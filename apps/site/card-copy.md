# Explainer card copy

Proposed subtext for each category card under the hero. Current copy is Latin
lorem; targets are one short line (~50–70 chars) to match the existing layout.

Logos are citations, not labels. Two kinds in play:

- **Wikipedia mark** → the concept's canonical article.
- **Doc icon** (projector rainbow theme) → the concept's doc in the projector
  GitHub repo. Both docs are stubbed at `packages/projector/docs/`.
